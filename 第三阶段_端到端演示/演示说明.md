# 端到端演示说明

## 演示目标

现场使用 `examples/输入剧本.txt` 的中文短剧本，完整展示从输入剧本到四份结构化结果的全过程。随包结果由正式代码全自动生成。

## 网页演示

打开 [网页演示界面](网页演示/index.html)，页面会自动运行内置《红色钥匙》示例。现场操作顺序：

1. 展示或修改中文剧本。
2. 点击“解析并生成”。
3. 依次切换“剧本解析”“资产四视图”“分镜”“提示词”。
4. 在“分镜”中展示非空解说词和不同镜头方案；在“提示词”中展示动态负面词。
5. 点击“下载全部四份”保存结果。

接口配置为空时使用本地确定性规则。完整填写服务地址、模型名称和访问密钥时，页面会真实调用兼容 API（应用程序接口）优化解说词和提示词。

## 命令行现场运行

在项目根目录执行：

```powershell
python scripts/run_pipeline.py `
  --input "examples/输入剧本.txt" `
  --output-dir "第三阶段_端到端演示/输出" `
  --project-id "red_key_demo" `
  --style-name "悬疑电影写实风格" `
  --rendering "写实电影摄影，轻微胶片颗粒" `
  --color-palette "低饱和冷色，红色作为视觉强调" `
  --period "当代旧公寓" `
  --lighting "夜间低调照明，柔和阴影"
```

随后执行测试：

```powershell
python -m unittest discover -s tests -v
```

## 代码讲解顺序

1. `parse_script.py`：中英文剧本解析和角色、场景、动作、对白、道具提取。
2. `generate_assets.py`：统一视觉风格下的资产四视图数据。
3. `generate_storyboard.py`：非空解说词、镜头变化和动态提示词。
4. `llm_client.py`：可选的真实模型调用及结果约束。
5. `run_pipeline.py`：完整流水线编排。
6. `tests/test_pipeline.py`：19 项稳定性和回归测试。

示例生成来源详见项目根目录的 `中文示例生成说明.md`。
